# Daithya Bikes: proposta de nova landing page

Versão de demonstração da página de revenda da Daithya Bikes, para comparar com o site atual (daithyabikes.com.br).

- Rodar local: `npm install` e depois `npm run dev`
- Publicada em: https://bsoarees.github.io/daithya-lp/ (cada push na `main` republica sozinho)
- Preços e modelos: `src/data/modelos.ts`

Não há carrinho nem pagamento: os pedidos vão pelo WhatsApp do comercial (botões dos modelos e simulador de pedido). A página está marcada para não aparecer no Google.
